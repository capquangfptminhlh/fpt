# SEO 90-Day Ranking Program

Status: ACTIVE
Start: 2026-08-18
Horizon: 90 days
Primary site: https://capquangfptminhlh.github.io/fpt/

## Objective

Maximize the share of commercially useful FPT-related queries reaching Top 3–10 within 90 days while preserving people-first quality and avoiding doorway/scaled-content abuse.

This is an operating target, not a guarantee of universal Top 1 placement. Head terms are competed by the official FPT domain and established local domains, so the program prioritizes a portfolio of head, commercial long-tail, local, comparison, support and informational queries.

## Non-negotiable rules

1. No mass name-swap local pages.
2. No fabricated local infrastructure, promotion, installation time, price or coverage claim.
3. No publishing just to hit a word count or URL quota.
4. Every indexable page must have a clear user job, canonical owner and internal-link role.
5. Time-sensitive price/promotion/device facts must be re-verified before publication.
6. Empty local-news hubs remain noindex until they contain evidence-backed local value.
7. New pages that overlap an existing canonical intent must merge into the existing owner instead of creating cannibalization.
8. Refresh winners and near-winners before creating more weak URLs.

## Phase 1 — Days 1–14: Crawl, index, trust, conversion

### P0 indexing
- Verify production canonical origin on every indexable URL.
- Verify sitemap = indexable URL set.
- Keep noindex pages out of sitemap.
- Verify every priority page is reachable with crawlable `<a>` links.
- Register/verify Search Console property and submit sitemap.
- Inspect homepage, top money pages and representative local pages with URL Inspection.
- Track indexed / discovered / crawled-not-indexed / duplicate-canonical states.

### P0 domain/brand
- Move from a GitHub project subpath to a real custom domain as soon as a domain is available.
- Preserve all URLs and add redirects/canonical migration mapping if origin changes.
- Add/strengthen About, editorial methodology, update policy and contact/trust information without pretending to be the corporate FPT website.

### P0 commercial UX
- Keep pricing/package cards fast, crawlable and content-visible without requiring JS.
- Preserve package detail links and conversion CTA.
- No source/debug/governance language in visible sales UI.

## Phase 2 — Days 15–30: Strengthen canonical owners

For each Tier A owner:
- answer the buying question above the fold;
- include current package/technology decision support;
- add comparison blocks and objections;
- add genuine FAQ only where visible content answers the question;
- add relevant Breadcrumb/Service/Article structured data where valid;
- link to 4–10 supporting pages and receive links back from those pages;
- refresh title/description only when SERP intent or CTR evidence supports it;
- add unique images/diagrams where they improve understanding.

Outcome gate by Day 30:
- 100% priority URLs indexable and internally linked;
- no orphan indexable URLs;
- no duplicate canonical owners;
- all 34 province landings pass quality/evidence gates;
- first Search Console query/page baseline captured.

## Phase 3 — Days 31–60: Build authority clusters, not volume for volume’s sake

Publish/update content only when it fills a mapped query gap. Prefer 2 strong pieces/updates per day over mass generation.

High-value clusters:
1. Pricing and package selection
2. WiFi coverage / Mesh / multi-floor houses
3. Gaming / latency / F-Game
4. WiFi 7 / XGS-PON / SpeedX
5. Camera / cloud / smart-home
6. FPT Play / sports / entertainment
7. Installation / fees / moving / cancellation
8. Speed troubleshooting / device capacity
9. Business Internet and branch-use cases
10. Evidence-backed local questions

Every support page must link to its money-page owner and at least one sibling only when contextually useful.

Outcome gate by Day 60:
- near-winner query set (positions 4–20) identified;
- pages with impressions but weak CTR get title/snippet testing;
- pages with position 8–20 get content/internal-link reinforcement;
- pages with zero impressions after sufficient crawl time are reviewed for merge, noindex or stronger value;
- no uncontrolled URL growth.

## Phase 4 — Days 61–90: Win near-winners

Weekly priority order:
1. Queries at positions 4–10 with commercial value.
2. Queries at positions 11–20 with strong impressions.
3. Local pages already receiving impressions.
4. Pages with cannibalization or wrong landing-page selection.
5. Authority gaps against current SERP leaders.

Actions:
- refresh facts and examples;
- improve answer-first sections;
- strengthen contextual internal links;
- consolidate overlapping pages;
- improve snippets/CTR;
- add first-hand evidence, screenshots, calculations, comparison tables or process detail where available;
- earn relevant mentions/links through genuinely useful assets, tools, data and community distribution rather than link spam.

- Pages at positions 4–10
- Pages at positions 11–20

- Duplicate/cannibalized query clusters
- Leads from organic traffic

## 30 / 60 / 90 day decision rules

### Day 30
If indexing is incomplete, stop expanding content and fix crawl/index/canonical/trust issues first.

### Day 60
If pages are indexed but not earning impressions, re-check intent fit and usefulness before publishing more URLs.

### Day 90
Judge success by query distribution and commercial traffic, not by a claim that every tracked keyword is Top 1. Continue only clusters with evidence of demand and ranking movement; merge/noindex weak duplicated inventory.

## Current hard blocker for aggressive 90-day SEO

The current production origin is a GitHub project Pages subpath. The existing QA already notes that host-root robots control requires a custom domain or root github.io site. A custom domain plus Search Console verification is therefore P0 for a serious 90-day commercial SEO campaign.
